# Farmers Listing Helper

Snap a photo of an item → get a store-ready product name, description, and social post in the house style of
Farmers Hardware & Home Furnishings (Somerville, TN). Includes a "New version" button, one-tap copy, price /
compare-at fields, and a Memphis · Nashville · Atlanta price check.

- Single static page (`index.html`), hosted on GitHub Pages.
- Uses Claude (Anthropic API) for vision + writing, and web search for price comparisons.
- The API key is entered once in ⚙︎ Setup and stored only in that phone's browser.

Roadmap: push listings directly into the Square Online store (Square Catalog API).
